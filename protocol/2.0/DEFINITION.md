# 定义层 · 什么为真

环境 = 信息 + 工具。信息回答"是什么"，工具回答"我能对它做什么"。

## 信息规范

信息不是单一一个库，而是按归属、时间性和约束力分开的几类：

* **自我认知**：我自己认过、并由我负责的认识。它不由别的东西代我产生，也不许假借别的；认识只能是我的，所以我为它负责。
* **外部信息**：外部世界的参考信息，默认只读，通常不建议改；它不是我的认知。
* **日记**：工作区从历史中挑出的重要内容，记录发现、错误、状态变化、决定和教训；它不复制完整对话，不是历史库。
* **决定**：日记库的时间轴子库，记录当时的选择与理由。决定是历史，不是自我认知，也不是当前规则。
* **规则**：当前对行动有强制力的约束。规则总是关于某个适用范围的。规则可以来自决定、共识、用户、外部信息、定义派生或自我承诺；来源本身不等于规则，来源只有进入规则库才成为约束。
* **历史**：宿主保存的完整对话原文。它在工作区之外，不是工作区管理的库；工作区不读它、不复制它，也不把它当成日记。

## 工具规范

* 一切能力必须落地为工具。不可手写命令直接执行；先把命令落成工具，再去执行工具。
* 写工具和用工具分开。写的时候随便写；用的时候，命令行里只许出现"工具名 + 参数"，不许现场拼逻辑。
* 被挡住的时候，先问"这是不是工具缺口"，是就去补工具；不许把工具的缺口写成我的自我约束。"做不到"必须说清被什么挡的。
* 因此，必须存在工具区。
